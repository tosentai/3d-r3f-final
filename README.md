## 📖 1. Опис проекту
**"The Celestial Monolith & Floating Sanctuary"** — це високотехнологічна 3D інтерактивна сцена у реальному часі, розроблена з використанням екосистеми Three.js / React Three Fiber, WebAssembly фізичного рушія Rapier та кастомних GLSL шейдерів.

Сюжет переносить глядача на стародавній ширяючий острів посеред небесного простору, де у центрі левітує загадковий артефакт давніх цивілізацій, оточений рунічними колонами, жертовниками з живим вогнем та діючим порталом крізь простір і час.

Користувач може досліджувати острів з різних ракурсів, змінювати час доби (ранок/день, захід сонця, космічна ніч), взаємодіяти з фізичними об'єктами (спавнити куби, сфери, піраміди), змінювати вектор гравітації та спостерігати кінематографічні ефекти рендеру (Bloom, Vignette, ACES Filmic Tone Mapping).

## 🔬 3. Математика та архітектура Кастомного Шейдера (GLSL)

Шейдер знаходиться у файлі `src/shaders/portalShader.js`.

### 3.1. Vertex Shader (Вершинний шейдер)
Зміщує вершини мембрани вздовж їхніх нормалей:
$$\text{pos}' = \text{pos} + \mathbf{n} \cdot \Delta h$$
$$\Delta h = \left( \sin(r \cdot 6.0 - t \cdot 2.5) \cdot 0.12 + \cos(x \cdot 4.0 + t \cdot 1.8) \sin(y \cdot 4.0 + t \cdot 1.8) \cdot 0.08 \right) \cdot uDistortion$$
Це створює ефект живого коливання мембрани просторово-часового переходу.

### 3.2. Fragment Shader (Фрагментний шейдер)
1. **Полярні координати**:
   $$r = \|\mathbf{uv} - (0.5, 0.5)\|$$
   $$\theta = \operatorname{atan2}(uv_y - 0.5, uv_x - 0.5)$$
2. **Диференціальне завихрення (Swirl Effect)**:
   $$\theta_{swirl} = \theta + \frac{0.8}{r + 0.15} - t \cdot \text{speed}$$
3. **Фрактальний броунівський рух (FBM Noise)**:
   Генерація 4 октав псевдовипадкового процедурного шуму для моделювання плазми.
4. **Ефект Френеля (Fresnel Rim Glow)**:
   $$F = (1.0 - |\mathbf{n} \cdot \mathbf{v}|)^{2.5}$$
   Забезпечує яскраве світіння по периметру під гострими кутами погляду.

## 🕹️ 4. Керування та Інтерактивність

* **Огляд сцени:** 
  * Ліва клавіша миші + потягнути: обертання камери (OrbitControls з інерцією `dampingFactor = 0.05`).
  * Колесо миші: плавне масштабування (наближення/віддалення).
  * Права клавіша миші: панорамування.
* **Спавн об'єктів:** кнопки `Куб`, `Сфера`, `Піраміда` на нижній панелі миттєво спавнять фізичні об'єкти над островом.
* **Фізична взаємодія:** клік по будь-якій руні надає їй спрямований фізичний імпульс вгору (`applyImpulse`).
* **Зміна гравітації:**
  * `1.0G (Норма)`: стандартне земне тяжіння $[0, -9.81, 0]$.
  * `0.2G (Місяць)`: уповільнене ширяюче падіння $[0, -2.5, 0]$.
  * `Антигравітація`: вектор сили спрямовується вгору $[0, 2.8, 0]$, відриваючи предмети у повітря.
* **Зміна доби:** перемикання між Сонцем у зеніті, золотистим Заходом сонця та космічною Ніччю.
* **Ракурси камери:** кнопки `Огляд`, `Портал`, `Вівтар` плавно переводять камеру на ключові об'єкти.

## 🛠️ 5. Локальний запуск проекту

1. Склонувати репозиторій:
```bash
git clone https://github.com/tosentai/3d-r3f-final.git
cd 3d-r3f-final
```

2. Встановити залежності:
```bash
npm install
```

3. Запустити локальний сервер розробки:
```bash
npm run dev
```
Відкрити у браузері `http://localhost:3000`.

4. Створити production білд:
```bash
npm run build
```
